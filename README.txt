1. Create a free GitHub account and a new repository.
2. Upload everything in this folder (keep the .github folder and www folder).
3. Open the Actions tab, run "Build APK", wait about 5 minutes.
4. Open the finished run, download the "study-tracker-apk" artifact, unzip, install app-debug.apk (allow "install unknown apps").
PDFs you add are copied to Documents/StudyTracker on your phone.

Icon and splash screen are in the assets folder and are applied automatically during the build.
